# Trained Model

The trained Sequence-to-Sequence RNN model is available on Google Drive.

**Download Model:** [\[Google Drive Link\]](https://drive.google.com/file/d/1LUsrjScaoL2fl_wGw6nzSEC690wBcEFT/view?usp=sharing)

## Model Information

* Model: Urdu Question Generation Sequence-to-Sequence RNN
* Framework: PyTorch
* Model Type: Encoder-Decoder RNN
* Dataset: Urdu Question Generation Dataset

Download the model and place the model files in this `model/` directory before running inference.
